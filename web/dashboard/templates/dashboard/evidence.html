Limits of these results

  • All data is simulated. Scam patterns follow public descriptions of UPI fraud, but exact numbers depend on simulator assumptions.
  • Fraud is over-represented (about 2% of payments) so models see enough examples. At a real bank's fraud rate, precision would be lower.
  • The first 48 hours of any file lack history and are not scored. A real deployment would keep history in a feature store.
  • Ring detection looks at the whole file, including later payments, so it supports investigation rather than real-time blocking.
